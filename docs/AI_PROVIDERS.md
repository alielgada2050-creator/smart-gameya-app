# مزودو الذكاء الاصطناعي المجانيون — الخطة البديلة (ADR-004)

> المرجع: قائمة `free-llm-api-resources` (cheahjs) ومراجعة لحدودها وسياسات بياناتها بتاريخ أغسطس 2026. الحدود تتغير كثيراً: راجع لوحة كل مزود قبل الإطلاق.

## الاختيار
| الترتيب | المزود | لماذا | الحد المجاني (للاسترشاد فقط) | البيانات |
|---|---|---|---|---|
| 1 أساسي | **Groq** — `llama-3.3-70b-versatile` | سريع، نموذج 70B جيد بالعربية، OpenAI-compatible | Llama 3.3 70B: نحو 1,000 طلب/يوم و12,000 توكن/دقيقة | لا احتفاظ ببيانات الاستدلال افتراضياً |
| 2 احتياطي | **Cloudflare Workers AI** — `@cf/meta/llama-3.3-70b-instruct-fp8-fast` | شبكة مختلفة تماماً عن الأساسي، OpenAI-compatible | نحو 10,000 Neuron/يوم (تتجدد 00:00 UTC) | تتعهد بعدم استخدام المدخلات للتدريب دون موافقة |
| 3 أخير | **قالب عربي ثابت** (بلا نموذج) | التطبيق لا يتوقف أبداً على حصة مجانية | غير محدود | لا شيء يغادر الخادم |

**مستبعد لبيانات المستخدمين:** Google AI Studio المجاني (قد تُستخدم المدخلات لتحسين منتجات Google؛ الطبقة المدفوعة لا)، ونماذج OpenRouter المجانية (بعض المزودين خلفها يسجلون أو يدربون على المدخلات)، وNVIDIA NIM المجاني (يُسجَّل الاستخدام). متاحة في الإعدادات للتطوير فقط.

## ماذا يحدث عند نفاد الحصة؟
المزود يرد 429 ← ننتقل للاحتياطي ← إن نفد أيضاً يُعرض القالب الثابت. الأرقام لا تتأثر لأنها لا تأتي من النموذج أصلاً. كل محاولة تُسجّل في `ai_model_usage` لمراقبة الاستهلاك.

## ضمانات الخصوصية والدقة
1. **ما يُرسل للنموذج:** حقائق مجمّعة فقط (المتبقي بعد المصاريف، القدرة، السيناريوهات). لا اسم، لا جوال، لا اسم جمعية، ولا الدخل الخام. مُختبر.
2. **حارس الأرقام:** أي رقم في رد النموذج غير موجود في الحقائق (بما فيها الأرقام الهندية ١٢٣ والفواصل) يُسقط الرد ويُستخدم القالب.
3. **حالة "لا ننصح بالانضمام":** لا تُرسل لأي نموذج إطلاقاً؛ القالب فقط.
4. **السجل:** لا نحفظ نص الطلب ولا الرد ولا مدخلات المستخدم المالية؛ فقط المزود والنتيجة والزمن وعدد التوكنات.
5. **الإقامة:** المزودان خارج المملكة؛ لأن ما يُرسل مجمّع وغير معرّف قلّ أثر نقل البيانات، لكن يُراجع ضمن تقييم PDPL.

## الإعداد (على الخادم فقط)
```bash
# لا تلصق المفاتيح في المحادثات ولا تضعها في git. ضعها في مدير الأسرار أو ملف .env محلي.
AI_PROVIDERS=groq,cloudflare
GROQ_API_KEY=...                 # console.groq.com → API Keys
CLOUDFLARE_API_TOKEN=...         # Cloudflare dashboard → Workers AI → API token
CLOUDFLARE_ACCOUNT_ID=...
# اختياري: تغيير النموذج
AI_MODEL_GROQ=llama-3.3-70b-versatile
```
عند التشغيل يطبع الخادم السلسلة الفعلية، مثل: `AI providers: groq/llama-3.3-70b-versatile → cloudflare/... → template`، ويذكر أي مزود تخطاه لنقص مفتاح.
بدون أي مفتاح يعمل المستشار بالقالب الثابت.

## إضافة مزود آخر
أي خدمة OpenAI-compatible تُضاف في `packages/ai-core/src/providers.ts` (`PRESETS`) أو عبر `AI_BASE_URL_<NAME>`. لا تستخدم نقاط نهاية غير رسمية أو مُهندسة عكسياً، ولا تتحايل على حدود الحصص المجانية.
