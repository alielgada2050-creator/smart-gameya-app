# SRS — Smart Gam'eya (مسودة للاعتماد — Gate A)

## 1. الغرض والنطاق
منصة لإدارة الجمعيات الدورية (ROSCA) للسوق السعودي، عربي/إنجليزي. يحدد MVP نطاقاً **غير ماسك للأموال**: المنصة تنظم الالتزامات والجدولة والقرعة والتذكير والسجلات، والدفع يتم عبر مزود مرخص فقط بعد اعتماد المسار النظامي.

## 2. أنواع المستخدمين
SUPER_ADMIN, PLATFORM_ADMIN, COMPLIANCE_OFFICER, FINANCE_ADMIN, SUPPORT_AGENT, GAMIYA_CREATOR, GAMIYA_MANAGER, GAMIYA_MEMBER, AUDITOR — صلاحيات مستقلة لكل جمعية، Maker–Checker للعمليات المالية.

## 4. متطلبات غير وظيفية
- الأمن: OWASP ASVS L2، MFA للإدارة، تشفير at-rest/in-transit، أقل صلاحية.
- الدقة: لا أعداد عشرية عائمة للمبالغ (bigint minor units / NUMERIC).
- الأداء: P95 < 500ms للعمليات الداخلية.
- الخصوصية: PDPL؛ تقليل البيانات؛ لا استخدام صور الهوية لتدريب نماذج.
- اللغات: RTL/LTR، التاريخ الميلادي مع عرض هجري اختياري، المنطقة الزمنية Asia/Riyadh للعرض و UTC للتخزين.

## 5. خارج نطاق MVP
مسك الأموال أو الضمان، تغطية المتعثرين، المطابقة بين غرباء، البطاقات، الإقراض.
